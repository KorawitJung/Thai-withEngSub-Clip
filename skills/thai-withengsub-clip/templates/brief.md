# Brief

ถามรวดเดียวตอนเริ่ม ข้ามข้อที่มีใน `channel.json` หรือเดาได้จากคำขอ

## เรื่อง
1. เรื่องหรือสถานที่:
2. จุดจบ: หักมุมด้วยความรู้ / ค้างไว้ต่อตอนหน้า
3. จำนวนตอนและเวลาสูงสุดต่อคลิป: เขียนบทให้พอดีตั้งแต่แรก
4. ภาษา: ไทย / อังกฤษ / ซับสองภาษา / พูดปนกัน / แยกสองเวอร์ชัน

## ภาพ
5. คลิปตัวอย่างสไตล์:
6. ผู้เล่าบนจอ: มีหรือไม่ และรูปอ้างอิงถ้ามี
7. โทน: สดใส / มืด และช่วงเวลาในเรื่อง
8. ฉากหลัง: นิ่ง / มีกล้องซูม
9. ภาพจริงที่อยากใช้: หรือให้หารูปสถานที่จริงที่สัญญาอนุญาต

## เสียง
10. เสียงพากย์และอารมณ์:
11. ดนตรี เสียงประกอบ และเสียงที่ไม่ต้องการ:

## แบรนด์และส่งงาน
12. ฟอนต์:
13. โลโก้ ประโยคปิดท้าย เช่น ชวนติดตาม และเวลาแช่หน้าสุดท้าย: ต้องรู้ก่อนอนุมัติบท เพราะอยู่ในเสียงพากย์
14. ต้องการ: ปก / แคปชันโพสต์ / แฮชแท็ก
15. ใช้เชิงพาณิชย์ไหม: มีผลกับภาพ เสียง และแพ็ก ElevenLabs

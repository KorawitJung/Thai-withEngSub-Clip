# ภาพจริง ปก และแคปชัน

## ภาพจริง
- ค้นว่าสถานที่หรือสิ่งที่พูดถึงหน้าตาอย่างไรตั้งแต่ขั้นตรวจข้อเท็จจริง เพราะแก้บทหลังอัดเสียงเสียเครดิต
- ใช้ภาพจากแหล่งที่ระบุสัญญาชัดเจน เช่น Wikimedia Commons และบันทึกผู้สร้าง สัญญา และลิงก์ลง `credits.md`
- ใส่เครดิตในคลิป ปก และแคปชัน ถ้าเป็น CC BY-SA ให้แจ้งผู้ใช้เรื่อง ShareAlike ก่อนใช้เชิงพาณิชย์
- ในช็อตใช้ `photo_card("@photo", "assets/x.jpg", "ภาพ: ผู้สร้าง · CC BY-SA 4.0", tag="ภาพจริง")` คู่กับ `motion=rise("#@photo", 0.2)` และซ่อนผู้เล่าในช็อตนั้น

## ปก
```bash
python $SKILL/scripts/cover.py cover --title "ชื่อเรื่อง" --kicker "มีจริงไหม?" --sub "บรรทัดรอง" --photo bg.jpg --credit "ภาพ: ผู้สร้าง · สัญญา" --preset story-warm
```
ใช้ `--inset` และ `--tag` เพิ่มภาพเล็กในกรอบ ใช้ `--logo` เพิ่มโลโก้ และทำแยกทุกภาษา

## แคปชันโพสต์
เขียน `post.md` แยกตามภาษา:
1. ประโยคเปิดเป็นคำถามเดียวกับคลิป
2. สรุปเนื้อหา 2–3 บรรทัดโดยไม่เฉลยจุดพลิก
3. ประโยคชวนดูจนจบ
4. สถานที่ เครดิตภาพและเสียง
5. หมายเหตุเมื่อเป็นเรื่องเล่าที่ยืนยันไม่ได้
6. แฮชแท็กที่ตรงเนื้อหา 5–10 คำ

# ภาพจริง ปก และแคปชัน

## ภาพจริง
- ค้นว่าสถานที่หรือสิ่งที่พูดถึงหน้าตาอย่างไรตั้งแต่ขั้นตรวจข้อเท็จจริง เพราะแก้บทหลังอัดเสียงเสียเครดิต
- ใช้ภาพจากแหล่งที่ระบุสัญญาชัดเจน เช่น Wikimedia Commons และบันทึกผู้สร้าง สัญญา และลิงก์ลง `credits.md`
- ค่าเริ่มต้นใส่เครดิตในคลิป ปก และแคปชัน ถ้าผู้ใช้ขอใส่เฉพาะแคปชัน ให้เอาออกจากคลิป ทำรายการพร้อมวาง และเตือนว่าเครดิตอาจหายถ้าคลิปถูกโพสต์ต่อ
- ถ้าเป็น CC BY-SA ให้แจ้งผู้ใช้เรื่อง ShareAlike ก่อนใช้เชิงพาณิชย์ และระบุ "ดัดแปลง" เมื่อปรับภาพ
- ภาพจาก Instagram, TikTok และ YouTube ใช้เป็นข้อมูลอ้างอิงได้ แต่ต้องได้รับอนุญาตก่อนนำมาใส่คลิป
- ถ้าผู้ใช้อยากได้ภาพเบลอฟุ้ง เก็บต้นฉบับไว้ แล้วใช้ `ffmpeg -i in.jpg -filter_complex "format=gbrp,split[a][b];[a]gblur=sigma=7[s];[b]gblur=sigma=28[g];[s][g]blend=all_mode=screen:all_opacity=0.35,format=yuvj420p" -q:v 3 out.jpg` ต้องมี `format=gbrp` ไม่เช่นนั้นสีเพี้ยนเป็นม่วง การเบลอไม่ได้ทำให้พ้นลิขสิทธิ์
- ไม่ต้องติดป้าย "ภาพจริง" เว้นแต่ผู้ใช้ขอ แต่ป้ายชื่อสถานที่ใช้ได้เมื่อตรงกับรูป
- ในช็อตใช้ `photo_card("@photo", "assets/x.jpg", "ภาพ: ผู้สร้าง · CC BY-SA 4.0", tag="ภาพจริง")` คู่กับ `motion=rise("#@photo", 0.2)` และซ่อนผู้เล่าในช็อตนั้น

## ปก
```bash
python $SKILL/scripts/cover.py cover --title "ชื่อเรื่อง" --kicker "มีจริงไหม?" --sub "บรรทัดรอง" --photo bg.jpg --credit "ภาพ: ผู้สร้าง · สัญญา" --preset story-warm
```
ใช้ `--inset` และ `--tag` เพิ่มภาพเล็กในกรอบ ใช้ `--logo` เพิ่มโลโก้ และทำแยกทุกภาษา

ถ้าคลิปทำด้วย Remotion ให้ทำปกเป็น composition ในโปรเจกต์เดียวกัน เพื่อใช้ฉาก ตัวละคร และฟอนต์เดิม แล้วรัน `npx remotion still` วางหัวข้อไว้ช่วงกลางภาพ เพื่อให้อ่านได้ตอนถูกครอปเป็นสี่เหลี่ยม และคำนึงว่าปกไม่ควรเฉลยจุดหักมุม

## แคปชันโพสต์
เขียน `post.md` แยกตามภาษา:
1. ประโยคเปิดเป็นคำถามเดียวกับคลิป
2. สรุปเนื้อหา 2–3 บรรทัดโดยไม่เฉลยจุดพลิก
3. ประโยคชวนดูจนจบ
4. สถานที่ แหล่งข้อมูล เครดิตภาพ GIF เสียง และข้อความโลโก้
5. หมายเหตุเมื่อเป็นเรื่องเล่าที่ยืนยันไม่ได้
6. แฮชแท็กที่ตรงเนื้อหา 5–10 คำ

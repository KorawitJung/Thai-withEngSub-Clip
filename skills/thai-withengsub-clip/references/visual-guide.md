# การวางภาพ

## เขียน episode.py
```python
from draw import *
from compose import rise, sway, flicker

def build(ep):
    ep.sound("assets/narration.wav")
    ep.shot("lift", line=0, art=backdrop() + elevator() + person(540, 1400),
            motion=flicker("#lift-glow"), zoom=1.08)
```
- ช็อตเริ่มที่ซับแถว `line` และจบเมื่อช็อตถัดไปเริ่ม ช็อตแรกต้องเริ่มที่ `line=0`
- เขียน `@ชื่อ` ใน `art`, `html`, `motion` แล้วระบบแปลงเป็น id ไม่ซ้ำกันของช็อต ในตัวเลือก CSS ใช้ `#@ชื่อ`
- โค้ด `motion` ใช้ `tl`, `T` (เวลาเริ่มช็อต), `D` (ความยาวช็อต) ได้ และต้องใช้ `fromTo`
- ชิ้นส่วนใหม่ให้เพิ่มใน `draw.py` เมื่อใช้ซ้ำได้ ถ้าใช้ครั้งเดียวเขียนใน `episode.py`

## ชิ้นส่วนเพิ่มเติม
- ใน `draw.py`: `plain`, `host`, `fact_card`, `pill`, `clock`, `versus`, `bars`, `signboard`
- การเคลื่อนไหว: `rise`, `pop`, `grow`, `sway`, `flicker`
- `ep.shot(..., label="// 01 · hook", counter="1 / 3")` เพิ่มป้ายเล็กด้านบน
- `ep.brand = "ชื่อช่อง"` ใส่ชื่อมุมจอ ส่วน `ep.outro("ชื่อ", "@handle")` ใส่หน้าปิดท้าย
- ในซับ ใช้ `*คำ*` เพื่อเน้น และ `|` เพื่อขึ้นบรรทัดใหม่

สไตล์ `explainer-paper` ซับอยู่ด้านบน 240–520 ให้วางเนื้อหาที่ 540–1200 และพิธีกรด้านล่าง ส่วนสไตล์อื่นใช้ตารางด้านล่าง

## หลักการภาพ
- ภาพเวกเตอร์แบนเต็มเฟรม ตัวเอกของภาพมีหนึ่งอย่างต่อช็อต
- ช็อตละ 2–8 วินาที การเคลื่อนไหวหลักหนึ่งอย่าง กล้องซูมช้าเล็กน้อย
- สีแดงสงวนไว้สำหรับอันตราย เปลี่ยนสไตล์ด้วย `--preset` หรือเพิ่มใน `PRESETS` และ `THEMES`

## พื้นที่บนจอ 1080×1920
| ช่วงแนวตั้ง | ใช้ทำ |
|---|---|
| 0–180 | ไม่มีตัวอักษร |
| 220–620 | การ์ดข้อมูล |
| 620–1100 | ตัวเอกของช็อต |
| 1120–1320 | ซับ |
| 1340–1920 | ฉากหลังเท่านั้น |

เว้นด้านขวาราว 140 พิกเซลจากตัวอักษร เพราะมีปุ่มของแอปบัง ค่านี้เป็นระยะเผื่อ ควรตรวจกับแอปจริง

## ข้อผิดพลาดที่เคยเจอ
| อาการ | สาเหตุ | แก้ |
|---|---|---|
| ซับทับตัวละคร | วางพื้นหรือตัวเอกต่ำเกินไป | ขยับขึ้นให้อยู่เหนือแถบซับ แล้วดูภาพจริงทุกช็อต |
| สระไทยทับบรรทัดถัดไป | ระยะบรรทัดแคบ | ใช้ระยะบรรทัดอย่างน้อย 1.4 |
| HyperFrames แจ้ง error เรื่องฟอนต์ | ไม่ได้ประกาศ `@font-face` | อย่าเขียนฟอนต์เองนอก `compose.py` ให้ใช้ `--font-*` |
| ตัวเอียงไทยไม่สวย | ฟอนต์ไม่มีตัวเอียงจริง | เน้นด้วยสีแทน |
| คนดูมึนหัว | กล้องขยับตลอด | ใช้ `--still` หรือ `"still": true` ใน `channel.json` |
| ตัวละครสั่น | การสั่นถี่ หรือเด้งตอนเปลี่ยนท่า | ใช้การเคลื่อนไหวช้าแบบ ease-in-out และไม่ใช้ `pop` กับตัวละคร |
| ภาพมืดหมอง | ขอบมืดและเงาแรงเกิน | ใช้ธีมสว่าง หรือ `time_sky(0.0–1.0)` ไล่ฟ้าตามเวลาในเรื่อง |
| ป้ายบนฟ้าสว่างอ่านไม่ออก | ตัวอักษรไม่มีขอบ | เพิ่มขอบเข้มหรือพื้นหลังป้าย |
| การ์ดหรือภาพจริงถูกผู้เล่าบัง | ใส่ผู้เล่าทุกช็อต | ซ่อนผู้เล่าในช็อตนั้น หรือให้กินไม่เกิน 2/3 ของจอ |
| ชุดตัวละครไม่ตรงต้นแบบ | วาดจากคำบรรยาย | ทำภาพรวมตัวละครหลายท่า และเทียบรูปอ้างอิงทีละชิ้นก่อนเรนเดอร์ |

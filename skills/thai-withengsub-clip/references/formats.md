# แนวคลิป ภาษา และสไตล์

เลือกจากเป้าหมายของคลิปก่อน แล้วจึงเลือกสไตล์ ตัวเลขด้านล่างมาจากคลิปตัวอย่าง 10 คลิป เป็นแนวทาง ไม่ใช่กฎ

## โหมดภาษา
| โหมด | เสียงพากย์ | ซับ | ตั้งค่า |
|---|---|---|---|
| ไทยล้วน | ไทย | ไทย | `show` ไทย, `--subs primary` |
| อังกฤษล้วน | อังกฤษ | อังกฤษ | `show` อังกฤษ, `--subs primary` |
| ไทย + ซับ 2 ภาษา | ไทย | ไทยใหญ่ อังกฤษเล็ก | `show` ไทย, `sub` อังกฤษ, `--subs both` |
| อังกฤษ + ซับ 2 ภาษา | อังกฤษ | อังกฤษใหญ่ ไทยเล็ก | `show` อังกฤษ, `sub` ไทย, `--subs both` |
| พูดไทย ซับอังกฤษ | ไทย | อังกฤษ | ใส่ทั้งสองช่อง, `--subs secondary` |
| ผสมในประโยค | ไทยปนอังกฤษ | ตามที่พูด | เขียนปนใน `narration.txt` และ `say` |
| แยก 2 เวอร์ชัน | ไทย 1 คลิป อังกฤษ 1 คลิป | ตามเสียง | ใช้ `episode.py` เดิม แยกโฟลเดอร์ narration, lines, audio, video |

หลักการแปล:
- ซับภาษาที่สองเขียนใหม่ให้เป็นธรรมชาติและสั้น ไม่แปลตรงคำ
- วลีไทยไม่ต้องตัดตามจังหวะเดียวกับอังกฤษ แต่ต้องสื่อความเดียวกันในแถวนั้น
- ข้อความในการ์ด ใส่สองภาษาเมื่อคนดูต้องอ่านเข้าใจ เช่น `translation=` หรือ `ไทย · English`
- ตรวจคำเฉพาะ เช่น ชื่อพิธีกรรม สถานที่ และหน่วยเงิน กับผู้ใช้เมื่อไม่แน่ใจ
- เวอร์ชันอังกฤษต้องปรับตัวอย่างให้คนต่างชาติเข้าใจ ไม่ใช่แปลอย่างเดียว

## สไตล์สำเร็จรูป (`--preset`)
| Preset | หน้าตา | ซับ | เหมาะกับ |
|---|---|---|---|
| `story-night` | ฉากกลางคืนเต็มเฟรม | กลางล่าง ซับรองในกล่องเล็ก | เอาชีวิตรอด เรื่องลึกลับ ตำนาน |
| `story-warm` | โทนอุ่นยามเย็น | เหมือน story-night | ไลฟ์สไตล์ รีวิวสถานที่ เรื่องเล่า |
| `horror-rules` | มืดจัด | สองบรรทัด บรรทัดล่างเป็นกล่องแดง | สยองแบบมีกฎ เรื่องผี |
| `explainer-paper` | พื้นกระดาษ พิธีกรด้านล่าง | หัวข้อด้านบน ขึ้นทีละคำ คำเน้นตัวเอียงแดง | สอนใช้เครื่องมือ ธุรกิจ เล่าเรื่องส่วนตัว |
| `data-clean` | พื้นขาว การ์ดกลางจอ | ใต้การ์ด จากจางเป็นเข้มทีละคำ | ข่าว เทคโนโลยี รีวิว เปรียบเทียบตัวเลข |

## แนวคลิป
| แนว | ความยาว | โครง | ชิ้นส่วนแนะนำ |
|---|---|---|---|
| เรื่องลุ้นเอาชีวิตรอด | 55–85 วิ | ดึงความสนใจ → กฎ → ไต่ระดับ → พลิก | `clock`, `fact_card` |
| ตำนาน/เรื่องเล่าสั้น | 15–30 วิ | คำถาม "ถ้า…" → ความเชื่อ → ภาพจบ → โลโก้ | `clock`, `ep.outro` |
| สยองแบบมีกฎ | 60–90 วิ | กฎที่ 1 → เรื่องผิดปกติ → กฎที่ 2 → จบค้าง | `signboard`, `ep.brand` |
| ไลฟ์สไตล์/โปรโมตสถานที่ | 60–80 วิ | ปัญหาใกล้ตัว → เทียบราคา → ความรู้ → ข้อเสนอ → โลโก้ | `versus`, `bars` |
| สอนเป็นขั้นตอน | 40–70 วิ | ผลลัพธ์ก่อน → จำนวนขั้น → ทีละขั้น → ชวนคอมเมนต์ | `label`, `counter`, `host` |
| อธิบายธุรกิจ/ความเห็น | 40–70 วิ | ข้ออ้างที่ขัดความเชื่อ → เหตุผล → ตัวอย่าง → ข้อสรุป | `host`, `fact_card`, `bars` |
| สรุปข่าว/ข้อมูล | 40–60 วิ | ข่าว → หัวข้อตัวเลข 3–4 ข้อ → ผลต่อคนดู → ชวนคอมเมนต์ | `pill`, `bars`, `versus` |

## หลักที่พบร่วมกัน
- เห็นเนื้อหาตั้งแต่เฟรมแรก ไม่มีหน้าชื่อเรื่อง
- จบเสียงพูดในจังหวะเดียวกับภาพ หรือจบด้วยโลโก้ 2–3 วินาที
- ทุกช็อตมีข้อมูลบนจอหนึ่งอย่างที่อ่านทันในเวลาที่ปรากฏ
- ตัวเลข ราคา และคำแนะนำด้านสุขภาพหรือความปลอดภัยต้องยืนยันแหล่งที่มา โฆษณาต้องบอกว่าเป็นโฆษณาเมื่อจำเป็น
- ใช้เป็นแนวทางเท่านั้น ห้ามลอกตัวละคร โลโก้ บท หรือองค์ประกอบเฉพาะของช่องอื่น
